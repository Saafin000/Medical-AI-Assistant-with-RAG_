IMPLEMENTATION DETAILS
================================================================================

RecursiveCharacterTextSplitter Configuration:

  chunk_size = 512              # Target chunk size in tokens
  chunk_overlap = 50            # Overlap between chunks in tokens
  separators = ["\n\n", "\n", " ", ""]  # Hierarchy of split boundaries
  length_function = token_counter       # Uses tiktoken for accurate counting
  keep_separator = False        # Don't duplicate separators in chunks

Token Counting:
  - Primary: tiktoken encoding for Qwen/GPT-3.5 models
  - Fallback: Character count ÷ 4 (rough approximation)
  - Accuracy: Within ~5% for typical English text

Error Handling:
  - If splitting fails: Return document as single chunk
  - If token counting fails: Use character count fallback
  - Graceful degradation (never throws exception)
