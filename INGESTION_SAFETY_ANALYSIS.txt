Each ingest_file() call:
  1. Parses document completely
  2. Processes images
  3. Chunks document
  4. Calls create_vectorstore() which:
     - Checks if collection exists
     - Creates new collection if needed
     - Initializes QdrantVectorStore
     - Calls add_documents() [LINE 151]
     - Calls docstore.mset() [LINE 154]
  5. Returns result dict
  6. If exception at ANY step → catches and returns {"success": False, "error": str(e)}

Scenario: First file succeeds, second fails

Step-by-step:
  1. First call: rag.ingest_file('Diabetes.pdf')
     - Parsing: ✓
     - Chunking: ✓
     - Add to Qdrant: ✓ COMMITTED
     - Add to docstore: ✓ COMMITTED
     - Return: {"success": True, "chunks_processed": 40}
     
  2. Second call: rag.ingest_file('Hypertension.pdf')
     - Parsing: ✓
     - Chunking: ✓
     - Add to Qdrant: ✓ ATTEMPTED
     - Error at docstore.mset(): ✗ FAILS
     - Exception caught at line 165
     - Return: {"success": False, "error": "docstore write error"}

Result:
  - Diabetes PDF: ✓ Fully ingested (can be queried)
  - Hypertension PDF: 
    - ⚠ Chunks MAY be in Qdrant (not rollback capability)
    - ✗ Chunks NOT in docstore (retrieval will fail)
    - Result: Inconsistent state (orphaned Qdrant points)

Code Evidence:

File: agents/rag_agent/vectorstore_qdrant.py (lines 151-154):
  ```python
  # Ingest documents into vector and doc stores
  qdrant_vectorstore.add_documents(documents=langchain_documents, ids=doc_ids)
  
  # Encode string chunks to bytes before storing
  encoded_chunks = [chunk.encode('utf-8') for chunk in document_chunks]
  docstore.mset(list(zip(doc_ids, encoded_chunks)))
  ```

Issue:
  - add_documents() commits to Qdrant
  - Then docstore.mset() is called
  - If docstore.mset() fails, Qdrant already has orphaned points
  - NO TRANSACTION / NO ROLLBACK

SAFETY: ⚠⚠⚠ RISKY - No transactional guarantee between Qdrant and docstore

[QUESTION 7: Is sequential two-file command safe?]
================================================================================

FINDING: YES, GENERALLY SAFE - But with caveats

Recommended Command:
  ```python
  rag.ingest_file('data/documents/Diagnosis and Management of Type 2 Diabetes.pdf')
  rag.ingest_file('data/documents/Hypertension.pdf')
  ```

Safety Analysis:

✓ SAFE ASPECTS:
  1. Both files exist and are readable (verified)
  2. Collection already exists (won't be recreated)
  3. Each file is parsed independently
  4. Add operations are append-only (no deletion)
  5. Sequential execution means first completes before second starts
  6. Error in first won't propagate to second

⚠ RISK ASPECTS:
  1. No duplicate detection between ingestions
     - If accidentally run twice, will create duplicates
  2. No transaction between Qdrant and docstore
     - If docstore write fails, orphaned chunks in Qdrant
  3. Long processing time (5-15 min each)
     - If interrupted, partial data left in stores
  4. No validation of chunks before storing
     - Invalid/empty chunks stored as-is

MITIGATION RECOMMENDED:
  1. Check result["success"] for each file
  2. Verify chunk counts reasonable (>20 each)
  3. Check for duplicates afterward
  4. Don't interrupt while processing

SAFER COMMAND VARIANT:
  ```python
  from agents.rag_agent import MedicalRAG
  from config import RAGConfig
  
  rag = MedicalRAG(RAGConfig())
  
  # Ingest first file
  ```

Option 2: Create separate Python script (SAFER for re-running)

  File: ingest_new_pdfs.py
  
  ```python
  import sys
  from agents.rag_agent import MedicalRAG
  from config import RAGConfig
  
  def ingest_with_validation(rag, filepath):
      print(f"\nIngesting: {filepath}")
      result = rag.ingest_file(filepath)
      
      if result["success"]:
          chunks = result.get("chunks_processed", 0)
          time_taken = result.get("processing_time", 0)
          print(f"  SUCCESS: {chunks} chunks in {time_taken:.1f}s")
          return True
      else:
          error = result.get("error", "Unknown error")
          print(f"  FAILED: {error}")
          return False
  
  if __name__ == "__main__":
      rag = MedicalRAG(RAGConfig())
      
      files = [
          'data/documents/Diagnosis and Management of Type 2 Diabetes.pdf',
          'data/documents/Hypertension.pdf'
      ]
      
      success_count = 0
      for filepath in files:
          if ingest_with_validation(rag, filepath):
              success_count += 1
          else:
              print(f"Stopping due to error in {filepath}")
              sys.exit(1)
      
      print(f"\nIngestion complete: {success_count}/{len(files)} files successful")
  ```
  
  Then run: .\venv\Scripts\python.exe ingest_new_pdfs.py
