================================================================================
EXACT DIFF: Key Changes to content_processor.py
================================================================================

1. _create_batches() - RETURN TYPE CHANGE
   OLD: def _create_batches(...) -> List[List[int]]:
   NEW: def _create_batches(...) -> List[List[tuple]]:

2. _create_batches() - BATCH STRUCTURE CHANGE
   OLD: batches.append([idx])                    # integer index
   NEW: current_batch.append((idx, 0))           # tuple for normal
        current_batch.append((idx, piece_idx))   # tuple for split pieces

3. chunk_document() - TUPLE UNPACKING
   OLD: for idx in batch_indices:
            if idx in self.split_sections_cache:
                batch_sections.extend(...)  # ALL pieces
   NEW: for section_idx, piece_idx in batch_items:
            if section_idx in self.split_sections_cache:
                piece = self.split_sections_cache[section_idx][piece_idx]
                batch_sections.append(piece)  # SPECIFIC piece

4. chunk_document() - MAPPING CALLS
   OLD: self._map_batch_splits_to_global(batch_splits, batch_indices)
        self._split_batch_for_413(batch_indices, section_chunks)
   NEW: self._map_batch_splits_to_global_v2(batch_splits, batch_items)
        self._split_batch_for_413_v2(batch_items, section_chunks)

5. NEW METHOD: _map_batch_splits_to_global_v2()
   Handles tuple-based batch items
   Maps local split IDs to global section IDs
   Deduplicates sections in split batches

6. NEW METHOD: _split_batch_for_413_v2()
   Binary splits tuple-based batches on HTTP 413
   Preserves all work items (no loss)
   Estimates batch tokens correctly for tuples

7. _merge_batch_results() - DUAL SUPPORT
   Handles both integer indices and tuples
   Extracts section_idx from tuples: last_section_idx = last_item_in_batch[0]

================================================================================
BEFORE vs AFTER (Example Scenario)
================================================================================

SCENARIO: Section 2 split into 2 pieces

BEFORE (BUGGY):
  _create_batches() returns:
    [[0, 1], [2], [2], [3, 4]]  ← [2] appears TWICE!
  
  chunk_document() expands:
    Batch 0: [0, 1] → sections 0, 1
    Batch 1: [2] → split_sections_cache[2] = ["piece1", "piece2"] (sent)
    Batch 2: [2] → split_sections_cache[2] = ["piece1", "piece2"] (sent AGAIN!)
    Batch 3: [3, 4] → sections 3, 4
  
  Result: BOTH pieces sent TWICE ❌

AFTER (FIXED):
  _create_batches() returns:
    [[(0, 0), (1, 0)], [(2, 0), (2, 1)], [(3, 0), (4, 0)]]
  
  chunk_document() expands:
    Batch 0: [(0,0), (1,0)] → section 0, section 1
    Batch 1: [(2,0), (2,1)] → piece 0 of section 2, piece 1 of section 2
    Batch 2: [(3,0), (4,0)] → section 3, section 4
  
  Result: Each piece sent ONCE ✅
